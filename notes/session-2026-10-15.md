## UIParser type error fixes

VS Code reported 6 Luau type errors in `UIParser/init.luau`. All are fixed, and the file now shows only the 7 existing unused-variable warnings. Not yet run in Studio.

### 1. Tokenizer: match end positions could be nil (2 errors)

`string.match` returns optional values, so the type checker didn't know the end position exists whenever the tag name matched. The `if` checks now test both.

Before:

```lua
if selfTag then
	...
	i = selfEnd
```

```lua
if openTag then
	...
	i = openEnd
```

After:

```lua
if selfTag and selfEnd then
	...
	i = selfEnd
```

```lua
if openTag and openEnd then
	...
	i = openEnd
```

### 2. `ParseTokens`: stack entries can have no node (1 error)

The bottom entry of the stack has `node = nil`, but the stack's type said `node` was always a `Node`. The type now allows nil. The loop reads the top of the stack once per token, so the type checker can narrow away nil, and every use goes through that variable.

Before:

```lua
local stack: Stack.Stack<{ node: Types.Node, children: { string } }> 
	= Stack.new({ { node = nil, children = root } } :: { { node: Types.Node?, children: { string } } })

...
while tokens[cursor].type ~= "EOF" do
	local token = tokens[cursor]

	if token.type == "Text" and token.value and stack:peek().node then
		table.insert(stack:peek().node.textBlob, token.value)
```

After:

```lua
-- The root entry has no node, so node is optional
local stack: Stack.Stack<{ node: Types.Node?, children: { string } }> 
	= Stack.new({ { node = nil, children = root } } :: { { node: Types.Node?, children: { string } } })

...
while tokens[cursor].type ~= "EOF" do
	local token = tokens[cursor]
	-- Read once per token so the type checker can narrow away nil
	const parent = stack:peek().node

	if token.type == "Text" and token.value and parent then
		table.insert(parent.textBlob, token.value)
```

The other uses of `stack:peek().node` changed the same way.

Setting `parentId` (self-closing and opening tags), before:

```lua
node.parentId = stack:peek().node and stack:peek().node.uniqueId
```

After:

```lua
node.parentId = parent and parent.uniqueId
```

Rich text, before:

```lua
const rawText, nextCursor = Parser.ReconstructRichText(tokens, cursor, token.tag)
table.insert(stack:peek().node.textBlob, rawText)
```

After:

```lua
const rawText, nextCursor = Parser.ReconstructRichText(tokens, cursor, token.tag)

if parent then
	table.insert(parent.textBlob, rawText)
end
```

**Behaviour change:** rich-text tags such as `<b>` at the very top level of the markup, outside any element, used to crash with "attempt to index nil". That text is now skipped. Inside elements, nothing changes.

Closing tags, before:

```lua
if not stack:peek().node or stack:peek().node.tag ~= token.tag then
	error(`Mismatched closing tag: expected </{stack:peek().node and stack:peek().node.tag}>, got </{token.tag}>`)
```

After:

```lua
if not parent or parent.tag ~= token.tag then
	error(`Mismatched closing tag: expected </{parent and parent.tag}>, got </{token.tag}>`)
```

### 3. `RenderNode`: comparing a non-optional object with nil (1 error)

`object` was typed `GuiObject` but really is nil when no prefab matches. It's now `GuiObject?`. The `assert` is removed, since the `if not object then error(...)` just before it already guarantees an object. The prefab branch assigns through a local, so the clone's `ClassName` can be read without a nil check.

Before:

```lua
local object: GuiObject

if node.tag == "prefab" then
	for _, prefab in CollectionService:GetTagged("prefab") do
		...
			object = prefab:Clone() :: GuiObject
			node.classname = object.ClassName
...
if not object then
	error(`Failed to create object of type with tag: { node.classname }, { node.tag }`)
end	

assert(object ~= nil and object and (object :: any):IsA("GuiObject"))

;(object :: GuiObject).LayoutOrder = node.order or -1
```

After:

```lua
-- Stays nil if no prefab matches; checked below
local object: GuiObject?

if node.tag == "prefab" then
	for _, prefab in CollectionService:GetTagged("prefab") do
		...
			const clone = prefab:Clone() :: GuiObject
			object = clone
			node.classname = clone.ClassName
...
if not object then
	error(`Failed to create object of type with tag: { node.classname }, { node.tag }`)
end	

;(object :: GuiObject).LayoutOrder = node.order or -1
```

### 4. `RenderNode`: setting `Text` through a union type (2 errors)

Luau can't set a property through `TextLabel | TextButton`. The text is now built first, then set through whichever class the object actually is.

Before:

```lua
if #node.textBlob > 0 then
	(object :: TextLabel | TextButton).Text = (table.concat(node.textBlob, " "):match("^%s*(.-)%s*$") or ""):gsub("\t+", "") :: string
elseif node.innerText then
	(object :: TextLabel | TextButton).Text = node.innerText:match("^%s*(.-)%s*$") :: string
end
```

After:

```lua
const text: string? = if #node.textBlob > 0
	then (table.concat(node.textBlob, " "):match("^%s*(.-)%s*$") or ""):gsub("\t+", "") :: string
	elseif node.innerText then node.innerText:match("^%s*(.-)%s*$") :: string
	else nil

-- Luau can't assign a property through a union type, so set it through each class
if text then
	if object:IsA("TextLabel") then
		(object :: TextLabel).Text = text
	else
		(object :: TextButton).Text = text
	end
end
```
